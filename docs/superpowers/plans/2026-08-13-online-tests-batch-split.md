# Online Tests Batch Split Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Split the aggregate online-test runner into four GAS launchers (`runOnlineTestsBatch1..4`) so the whole suite runs inside the 30-minute per-execution GAS limit without losing any coverage.

**Architecture:** Extract the setup/registration body of `executeFullOnlineTests` (`src/onlinetests/index.ts:314-350`) into a private `executeOnlineTestsBatch(groups, overrides)` helper that registers only the requested `FullOnlineTestRegistrations` keys. `executeFullOnlineTests` becomes a call with the full, order-preserving key list — observable behaviour unchanged. Four thin `executeOnlineTestsBatchN` + `runOnlineTestsBatchN` pairs mirror the existing `runReportedSuite` launcher pattern and are exposed to GAS through the same two-file bridge (`OnlineTestsEntry.ts` → `entrypoints/EntryPointOnlineTests.ts`) used by the 23 granular `test*` launchers.

**Tech Stack:** TypeScript (transpiled to GAS V8), Jest + ts-jest (`jest.config.cjs` for unit, `jest.build.config.cjs` for build smoke), webpack `online` build mode via `scripts/build-and-prepare.cjs`.

**Source spec:** `docs/superpowers/specs/2026-08-13-online-tests-batch-split-design.md`

## Global Constraints

- Target is **GAS V8**: synchronous code only, no Node/browser-only APIs, no `async`/`await`, no Promises.
- Native GAS globals (`DriveApp`, `SpreadsheetApp`, `PropertiesService`, …) may only be touched inside `GoogleApiWrapper` (L2). New code here must not reference them; ESLint `no-restricted-globals` fails the build otherwise.
- Never edit `dist/*` — it is generated by `scripts/build-and-prepare.cjs`.
- **GasLibraryFactory-first**: this plan adds no new logic, only re-composition of existing registration functions. Do not introduce helpers that duplicate library behaviour.
- `runFullOnlineTests` / `executeFullOnlineTests` must keep **identical observable behaviour**: same group order, same arguments, same report. Not deprecated, not removed.
- Batch execution order for the operator is **1 → 2 → 3 → 4**; batch 2 requires batch 1 to have run against the same persisted fixture. No runtime precondition guard is added (decision in spec, "Gestione errori").
- New launchers are developer-only: invoked from the Apps Script _Esegui_ dropdown. **No changes to `src/presentation/Menu.ts` or any Sheets UI.**
- Batch group assignment (spec, "Raggruppamento batch"), verbatim:
  - Batch 1: `documenti`, `jobRunner`
  - Batch 2: `email`, `articolazione`
  - Batch 3: `import`, `storico`, `itpDotted`, `aclReali`
  - Batch 4: `supplenzeRuoli`, `cacheIsolamento`, `permessi`
- Job names/types for `runReportedSuite`: `('online_tests_batch1'..'online_tests_batch4', 'ONLINE_TEST_SUITE_BATCH')`.

```ts
/** Registration order of the aggregate suite; batches below are subsets of this list. */
const ALL_ONLINE_TEST_GROUPS: ReadonlyArray<keyof FullOnlineTestRegistrations> = [
  'documenti',
  'email',
  'jobRunner',
  'import',
  'storico',
  'articolazione',
  'itpDotted',
  'supplenzeRuoli',
  'aclReali',
  'cacheIsolamento',
  'permessi'
];

/**
 * Shared body of the aggregate runner and of every batch launcher: reads the persisted fixture,
 * re-initialises Aldo against it and registers exactly the requested scenario groups.
 * `cacheIsolationDeps` is resolved lazily so batches without `cacheIsolamento` never require the
 * second master fixture.
 */
function executeOnlineTestsBatch(
  groups: ReadonlyArray<keyof FullOnlineTestRegistrations>,
  overrides: Partial<FullOnlineTestDeps> = {}
): OnlineTestReport {
  const properties = overrides.properties ?? new ScriptPropertiesFacade();
  const readSample = overrides.readSample ?? readPersistedFullOnlineTestSample;
  const sample = readSample(properties);
  const resetAldoFn = overrides.resetAldo ?? resetAldo;
  const initAldoFn = overrides.initAldo ?? initAldo;
  const clock = overrides.clock ?? ((): Date => new Date());
  const registrations = { ...futureScenarioRegistrations, ...overrides.registrations };

  resetAldoFn();
  const container = initAldoFn(clock(), properties, sample.masterSpreadsheetId);
  container
    .get<ContextBuilder>('contextBuilder')
    .registerInterceptor(e2eActiveRepresentativesInterceptor);

  const runner = new TestRunner();
  const testSample: FullOnlineTestSample = { ...sample, testMode: sample.masterTestMode };
  for (const key of groups) {
    if (key === 'email' || key === 'jobRunner') {
      (registrations[key] as RegisterEmailChecks)(runner, container, testSample, EMAIL_TEST_SAFE);
    } else if (key === 'cacheIsolamento') {
      registrations.cacheIsolamento(
        runner,
        container,
        testSample,
        cacheIsolationDeps(properties, overrides)
      );
    } else {
      (registrations[key] as RegisterSharedChecks)(runner, container, testSample);
    }
  }
  return runner.report();
}

export function executeFullOnlineTests(
  overrides: Partial<FullOnlineTestDeps> = {}
): OnlineTestReport {
  return executeOnlineTestsBatch(ALL_ONLINE_TEST_GROUPS, overrides);
}
```
