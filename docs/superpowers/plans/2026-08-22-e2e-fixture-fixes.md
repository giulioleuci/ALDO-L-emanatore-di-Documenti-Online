# E2E Fixture Fixes Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Fix the three diagnosed online-test failures by correcting two fixture-seeding configuration gaps (verbale/condotta folder resolution; missing GST column on prior-year CLASSI sheets) — zero production code changes.

**Architecture:** Both failures are data gaps in the online E2E fixtures, not defects in application code. Fix 1 adds `DATI_SORGENTE {metodo:'cartellePerClasse'}` to the cartelle box of two CONF_MAIL patterns so `renderBoxes` resolves real LOG_FOLD folders through `AggregatoreDati` (already wired at `ApplicationComposition.ts:125`; LOG_FOLD rows already carry `CLASSI='1A'/'2B'/'3C,3C-S,3C-C'`, matched by `AggregatoreDati.getCartellePerClasse` = "LOG_FOLD whose CLASSI contains the class"). Fix 2 declares a `GST` column on the prior-year CLASSI sheets so the framework's header-aligned `appendRow` stops silently dropping the seeded `GST→d4` cattedra value; the downstream chain (prior MATERIE catalog → teaching slots → `reconcileSigla('GST', annoCorso) === 'STO'` via EVOLUZIONE → titolare d4) is already correct.

**Tech Stack:** TypeScript compiled to Google Apps Script V8; Jest offline suites (`test/unit/**`); webpack `--mode=online` build pushed with clasp.

## Global Constraints

- Target runtime is GAS V8: synchronous code only, no Node-specific APIs.
- Native GAS globals (`SpreadsheetApp`, `DriveApp`, …) are forbidden outside L2 wrappers (ESLint-enforced); fixtures must keep using the `ISampleSpreadsheet` facade.
- Never edit `dist/*` — it is generated by `scripts/build-and-prepare.cjs`.
- Data-driven rule: mail/document behavior comes from DB rows (`CONF_MAIL`, `CONF_DOC`). These fixes go into seeders only; never touch pipeline services.
- **No `GasLibraryFactory` changes in this plan.** Hardening `SampleSpreadsheetBuilder.appendRow` (warn/throw on out-of-header keys) is deliberately deferred as a separate library decision.
- Verification commands are exact: `npm run typecheck`, `npm run lint`, `npm test`, `npm run build:online`.
